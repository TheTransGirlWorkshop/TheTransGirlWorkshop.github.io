Getting started

  1. Download and run the Windows installer.
  2. Open Workshop Launcher and sign in or create a Workshop account.
  3. Redeem a one-use invitation code or buy an available game. Open Library to install it.

The installer includes the app runtime and can install Microsoft WebView2 if needed. Sign-in, downloads and updates require internet access.
