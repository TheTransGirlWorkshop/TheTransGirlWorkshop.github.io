Getting started

Download. Sign in. Play.

  1. Download and run the Windows installer.
  2. Open the launcher and sign in or create your Workshop account.
  3. Redeem an invitation code if you have one, then install an available game from your library.

The installer includes the app runtime and can install Microsoft WebView2 if it is missing. An internet connection is needed for sign-in and downloads. This installer is currently unsigned.
