Privacy Policy

Last updated: 5 October 2026

Overview

TrapDoor is a Discord moderation bot operated by The Trans Girl Workshop. It provides a server-configured anti-spam honeypot that can automatically moderate accounts that post in a designated trap channel.

Data TrapDoor processes

TrapDoor may process Discord identifiers necessary to operate the service, including server IDs, channel IDs, role IDs, user IDs involved in moderation actions, and Discord account creation timestamps used in moderation logs.

Message content

TrapDoor reacts to the existence of a message in the configured honeypot channel. The current implementation does not require Discord's Message Content privileged intent and does not persist message content in TrapDoor's own database.

Data TrapDoor stores

TrapDoor stores per-server configuration including the Discord server ID, honeypot channel ID, moderation-log channel ID, enabled state and explicitly exempt role IDs.

Moderation logs

Moderation events are posted to the Discord server's configured TrapDoor log channel. Those messages remain subject to that server's own Discord permissions, retention settings and deletion choices.

Why data is processed

Data is processed to configure and operate the honeypot, determine exemptions, perform moderation actions requested by server administrators, maintain server configuration and create moderation logs.

Sharing

The Trans Girl Workshop does not sell TrapDoor user data. Discord separately processes information used through the Discord platform and API under Discord's own policies.

Retention

TrapDoor removes locally stored configuration for a server when the bot receives notice that it has left or been removed from that server. Moderation logs stored within Discord remain controlled by the server's administrators.

Third-party support links

TrapDoor and this website may link to third-party services such as Buy Me a Coffee and PayPal. Using those services is optional and subject to their own privacy practices.

Contact

For TrapDoor or privacy-related enquiries, contact The Trans Girl Workshop through its public GitHub presence at github.com/TheTransGirlWorkshop.
